# Fuse releases

Update channel for Fuse, a Mac app for real estate photo HDR. Installed copies read `appcast.xml`
from here and download updates from the `channel` release. Every update is signed; the app checks that
signature before installing it.

Install: download [Fuse.dmg](https://github.com/malloyjoshua/fuse-releases/releases/download/channel/Fuse.dmg)
and drag Fuse to Applications. Apple Silicon, macOS 14 or newer. The first open needs System Settings >
Privacy & Security > Open Anyway.
